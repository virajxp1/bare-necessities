# Page Blueprints

This document defines the structural blueprint for each major page.

## Home

The homepage should establish the point of view quickly and route the reader into work, writing, or personal context.

### Structure

1. Global navigation
2. Hero
3. Selected work
4. Latest writing
5. About / manifesto
6. Footer

### Hero

Goal:

- communicate what the site is about within a few seconds
- establish tone and confidence
- provide immediate paths into work and writing

Content:

- small availability pill
- oversized headline
- short supporting paragraph
- primary and secondary CTA

### Selected Work

Goal:

- prove judgment through a curated set of projects

Content:

- section label and heading
- 3 featured projects in stacked row format
- `View all` action linking to `/work`

### Latest Writing

Goal:

- show active thinking and perspective

Content:

- 3 recent posts
- `All posts` action linking to `/blog`

### About / Manifesto

Goal:

- explain who you are and how you think

Content:

- short intro
- principles or beliefs
- link to full `/about`

## Work Index

The work page should feel like a curated archive, not a thumbnail gallery.

### Structure

1. Page header
2. Intro paragraph
3. Project rows
4. Optional closing CTA

### Rules

- Lead with the strongest work
- Keep descriptions outcome-oriented
- Avoid equal-weight sorting if the projects are not equal in importance

## Project Detail Page

Every project detail page should read like a concise case study.

### Suggested Structure

1. Project title and role
2. Short summary
3. Context or problem
4. Constraints
5. Solution
6. Outcome
7. Stack and links
8. Next / related project

### Rules

- Focus on decisions and tradeoffs
- Avoid buzzword storytelling
- Use images only when they add explanatory value

## Blog Index

The blog index should prioritize readability and scannability.

### Structure

1. Page header
2. Optional short intro
3. Chronological post list or light card grid

### Rules

- Titles should dominate
- Metadata should support, not compete
- Categories can help orientation but should stay visually restrained

## Blog Post Page

Blog posts should be typography-first.

### Structure

1. Title
2. Metadata row
3. Prose content
4. Optional related reading or back link

### Rules

- Keep prose width narrow enough for sustained reading
- Code blocks should be clean and consistent
- Do not add decorative sidebars unless the content truly needs them

## About Page

The About page should deepen context without turning into a resume clone.

### Structure

1. Page header
2. Personal introduction
3. Working principles
4. Areas of focus
5. Optional current interests or `Now`
6. Contact links

### Rules

- Keep the writing specific and credible
- Show taste through selection, not through exhaustive history
- If experience history is included, keep it secondary to values and current direction
